# Contract: 화면 추가 (DRIVE DNA 보조 태그)

1차 `specs/001-drive-dna/contracts/ui.md`에 더하는 것만 적는다.

## 나의 DNA 칸 (1차 §7)

- 유형 코드·별칭 바로 아래에 판정된 태그 칩을 둔다(위임 결정 D6).
  - 칩은 초록(`green`) 글자에 새 색 `green_soft` 바탕이다. `green_soft`는 라이트 `#FFE3F7EC`, 다크 `#FF143726`이다.
  - 2열 격자(`Ui.grid(2, …)`, 같은 폭)로 놓아 다섯 개여도 줄이 넘치지 않는다.
  - 예: "크루즈 위임형", "여유 충전형", "루틴형", "동승 맞춤형", "빗길 한결형"
- 판정된 태그가 없고 `Profile.drives`(분석된 운전 수)가 1 이상이면 작은 글자로 "보조 태그는 운전이 더 쌓이면 보여요"를 보인다. 0이면 아무것도 두지 않는다(1차의 "운전이 끝나면 여기에 쌓여요"가 있다).
- 버튼 줄에 "태그  ›" 칩을 더한다. 아이콘은 기존 `ic_dna`다. 순서는 "운전 기록  ›", "16유형  ›", "태그  ›"다. 주행 중에는 흐리고 눌리지 않는다(1차).

## 태그 화면 (새, 16유형 화면처럼 오른쪽 "상황 칸"(1차 결과 화면 자리)을 덮는다)

- 제목 "보조 태그", 그 아래 작은 글자 "쌓인 운전으로 정해요 · 최근 100번"
- 태그마다 카드 한 장. 카드 안의 순서는 아래와 같다.
  1. 이름(크루즈, 충전, 이동 범위, 동승, 빗길)과 오른쪽의 판정 칩 또는 "보류" 칩
     - 판정 칩: `green` 글자에 `green_soft` 바탕
     - 보류 칩: `text3` 글자에 `chip` 바탕
  2. 근거 문장(있으면). 예: "장거리 운전 3번의 크루즈 비율 중앙값 70%"
  3. 보류 이유(보류일 때). 점선 테두리 상자 안에 둔다.
     - 테두리: `line` 색, 굵기 2dp, 점선 6dp·간격 4dp, 둥근 모서리 18dp
     - `GradientDrawable.setStroke(width, color, dashWidth, dashGap)`을 쓴다. 1차 보류 축 막대(`AxisBar`)의 점선과 같은 뜻이다.
     - 글자는 `text3`이다.
- 숨긴 태그(크루즈 신호 없음)는 카드가 없다.
- 맨 아래 작은 글자: "태그는 쌓인 운전으로 정하는 잠정 판정이에요. 성향에 좋고 나쁨은 없어요."
- "✕  닫기" 칩이 맨 위 오른쪽에 있다(16유형과 같다).
- 이동 범위 카드는 비율과 횟수만 보인다. 어디에도 주소·좌표가 없다.

## 근거·보류 문장 (data-model §4·§5)

| 카드 | 근거 예 | 보류 예 |
|---|---|---|
| 크루즈 | "장거리 운전 3번의 크루즈 비율 중앙값 70%" | "장거리 운전이 1번뿐이에요(3번 필요)", "크루즈를 쓰는 정도가 운전마다 달라요" |
| 충전 | "충전 3번의 충전 직전 배터리 중앙값 55%(집 충전 포함)" | "충전이 2번뿐이에요(3번 필요)", "충전하는 때가 그때그때 달라요" |
| 이동 범위 | "새 장소 3% · 자주 가는 2곳이 85%" | "운전이 12번 쌓였어요(20번 필요)", "새 곳과 늘 가던 곳이 섞여 있어요" |
| 동승 | "동승 운전 3번의 역동성 지수가 평소보다 40% 낮아요" | "동승 운전이 1번뿐이에요(3번 필요)", "평소와 차이가 애매해요(차이 18%)" |
| 빗길 | "비 운전 3번의 역동성 지수가 평소와 비슷해요(차이 4%)" | "비 운전이 2번뿐이에요(3번 필요)" |
