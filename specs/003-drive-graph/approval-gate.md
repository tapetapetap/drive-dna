# 2-1 구현 전 승인 게이트: DRIVE DNA 3차

- 승인: 사용자 위임. 사용자 메시지(2026-11-11 새벽): "내 승인 없이 모든 작업 진행해둬봐 … 나머지 두 앱에 대해서도 같은 내용은 아니여도 비슷하게 고도화 할 수 있는 부분들을 찾아 진행해. 자고 올 테니까 알아서 다 처리해봐"
- 그래서 게이트에서 보일 것(실사용 변화, goldfish 요약)과 위임으로 정한 것(D1~D16)을 여기에 남기고 구현으로 넘어간다. 아침에 사용자가 다시 본다.

## 실사용에서 달라지는 것

**운전자(P 화면)**
- 결과 화면 맨 위에 그래프 카드가 생긴다. 운전 동안의 속도 흐름(면과 선), 평균 점선, 급가속 ▲·급감속 ▼·빠른 조향 ◆ 표시, 처음·끝 시각, "▲ 급가속 n · ▼ 급감속 n · ◆ 빠른 조향 n" 줄이다. 그래서 유형 카드와 축 줄이 그만큼 아래로 내려간다.
- 방금 끝난 운전의 결과(끝 시각 10초 안, 한 결과에 한 번)는 네 글자가 차례로 떠오르고 DNA 타일 둘레로 링이 두 번 퍼진다. 다시 보기와 움직임 줄이기 설정에서는 없다.
- "한 가지 제안" 카드 아래에 방금 들은 음성 문장이 스피커 아이콘과 함께 있고, 말하기 시작한 때부터 6초 동안 소리 막대가 움직인다. 다시 보기에는 없다.
- 운전 기록 줄 왼쪽이 작은 그래프가 된다(그래프가 없는 1·2차 기록은 DNA 타일).
- 운전 기록 머리의 "비교"를 켜고 두 줄을 고르면 비교 화면이 열린다. 두 유형 카드, 겹친 그래프(파랑·초록), 축마다 두 점, "다른 축 n개 · 같은 축 m개(· 보류 k개)"다.
- 운전이 쌓여 보조 태그가 바뀌면 태그 카드에 "새로 정해짐" 또는 "방금 운전으로 바뀜" 칩과 "지난: …"이 붙고, 나의 DNA 칸에 "방금 운전으로 태그 근거 n개가 바뀌었어요" 줄이 생긴다(누르면 태그 화면, 주행 중에는 흐리게).
- 판단(네 축, 유형, 태그)과 음성 문장, 말하는 때는 그대로다.

**시연자**
- `seed`의 24개 기록 모두 그래프가 있다(시연 준비값). 새 장면 `compare`가 두 운전 비교를 보인다.

**저장**
- 운전 기록 한 줄에 필드 두 개(속도 구간, 사건)가 붙는다(한 줄 약 150자, 100개면 15KB 안팎). 1·2차 기록은 그대로 읽힌다. 위치는 더 저장하지 않는다.

**기존 사용자가 잃는 것**
- 없음. 1·2차 기록은 그래프 없이 DNA 타일로 보인다.

**예측할 수 없는 것**
- 없음. 링은 카드 밖으로 몇 dp 잘릴 수 있는데, 그때 링은 거의 투명하다(D14).

## 승인 뒤 구현 중 바뀐 것

- D11 좁힘(태그 바뀜): 에뮬레이터에서 운전 두 번 만에 "태그 근거 2개가 바뀌었어요"가 떴다. 보류 태그의 "운전이 1번 쌓였어요" → "2번"처럼 쌓인 수만 바뀐 것이었다. 운전마다 뜨면 정작 근거가 바뀐 때가 묻히므로, 보류 이유만 바뀐 것은 바뀜으로 보지 않는다(NONE). 판정이나 근거 문장(fact)이 바뀔 때만 칩을 붙인다. spec FR-040·US3-3, research R14, data-model §4, tasks T012, 테스트를 함께 고쳤다.
- 자막 시각: data-model §5의 `Spoken.at`은 `System.currentTimeMillis()`가 아니라 `SystemClock.uptimeMillis()`다. 소리 막대가 그리는 시계와 같게 했다(첫 앱 4차와 같은 방식).
