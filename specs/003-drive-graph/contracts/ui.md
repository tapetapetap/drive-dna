# 화면 계약: DRIVE DNA 3차

1·2차 `contracts/ui.md`(§6 상황 화면, §7 나의 DNA 칸)에 더한다. 문구는 아래 그대로 쓴다.

## §1 결과(상황 화면)

- 맨 위(작은 제목 "방금 끝난 운전 · …" 아래)에 그래프 카드가 있다.
  - 머리 "이번 운전 그래프"
  - 그래프(높이 180dp, research R13)
  - 아래 줄 "처음 오후 9:42 · 끝 오후 9:44"
  - 사건 줄 "▲ 급가속 n · ▼ 급감속 n · ◆ 빠른 조향 n"(횟수 0이거나 신호 없음(null)인 종류는 뺌, 모두 빠지면 "급한 조작 표시 없음")
  - 작은 글 "속도는 주행거리로 추정했어요"
- 그래프가 null인 분석 운전: 카드 자리에 작은 글 하나(data-model §6). 속도를 추정하지 못했으면 "이 운전은 속도를 추정하지 못해 그래프가 없어요", 1·2차 형식 기록이면 "이 기록은 그래프를 남기기 전 운전이에요"
- 유형 카드는 1차와 같다. fresh면 네 글자가 차례로 나타나고 타일 둘레 링이 두 번 퍼진다(research R16).
- 자막: "한 가지 제안" 카드 아래에 아래 줄이 있다.
  - `[스피커 아이콘][소리 막대 3개] "이번 운전은 G P S E, 차분한 계획가 쪽이었어요. 근거는 화면에서 볼 수 있어요."`
  - 22sp, 회색 카드
- 다시 보기: 그래프 카드는 있고, 공개 효과와 자막은 없다.

## §2 운전 기록

- 머리 오른쪽에 칩 두 개가 있다: "비교"(켜고 끄기)와 "✕  닫기". 분석 기록이 2개 미만이면 "비교"는 흐리고 눌리지 않는다.
- 줄: `[썸네일 120×56 또는 DNA 타일] 코드 · 별명 / 시각 · 거리 · 시간`
- 비교가 켜져 있으면 아래처럼 바뀐다.
  - 줄 오른쪽에 체크 원이 생긴다(고른 순서대로 파랑, 초록).
  - 목록 위에 안내 "비교할 운전 두 개를 고르세요", 아래에 버튼 "두 운전 비교"(2개일 때만 켜짐)가 있다.

## §3 비교 화면

- 머리: 작은 글 "두 운전", 제목 "운전 비교", "✕  닫기"
- 유형 카드 두 장(가로로 나란히)
  - 왼쪽 파랑 테두리, 오른쪽 초록 테두리
  - 네 글자(40sp), 별명, "11월 11일 오전 12:42 · 1.4km · 2분"(1·2차 `timeOfDay` 형식)
- 그래프 카드: 머리 "속도 흐름(처음~끝을 같은 폭으로)", 겹친 그래프. 그래프 없는 운전은 범례 옆에 "이 운전은 그래프가 없어요"
- 축 카드: 축마다 아래가 있다.
  - 축 이름
  - 막대(두 점: 파랑·초록)
  - 파랑 점과 관측 문장
  - 초록 점과 관측 문장
- 끝 줄 "다른 축 n개 · 같은 축 m개"(k > 0이면 " · 보류 k개"를 붙임). k = 한쪽이라도 보류인 축 수, n + m + k = 4(data-model §3)
- "✕  닫기"와 뒤로 가기는 운전 기록으로 돌아가고, 비교 모드와 고른 둘은 남는다(data-model §6)

## §4 보조 태그 화면

- 바뀐 태그 카드: 제목 줄에 칩 "방금 운전으로 바뀜"(파랑) 또는 "새로 정해짐"(초록)을 붙인다.
- 근거 문장 위에 지난 문장을 작게(20sp, 흐린 색) "지난: …"으로 보인다.

## §5 나의 DNA 칸

- 바뀐 태그가 있으면 태그 칩 줄 아래에 "방금 운전으로 태그 근거 n개가 바뀌었어요  ›"(파랑 글, 누르면 태그 화면, P에서만)
