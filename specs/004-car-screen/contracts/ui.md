# UI 계약: DRIVE DNA 4차 — 차 화면 개선

크기 단위는 sp(글자)·dp(칸)다. 에뮬레이터에서 1dp = 1px이다. "그대로"는 지금 값을 바꾸지 않는다는 뜻이다.

## §1 공통 도우미(`Ui`, Ui.kt)

| 도우미 | 지금 | 바뀜 |
|---|---|---|
| `small(s)` | 22sp, text3, 600 | **24sp** |
| `chip(label, fg, bg, icon)` | 20sp 600, 여백 18·9·20·9, 아이콘 22 | **24sp**, 여백 20·10·22·10, 아이콘 26. 누르지 않는 칩 전용 |
| `action(label, fg, bg, icon, onClick)` (새) | 없음 | `chip`과 같은 글자·색 + **최소 높이·폭 76dp**, 글자 가운데, 가로 여백 28 |
| `banner(text)` | 22sp | **24sp** |
| `body`, `headline` | 26 / 48sp | 그대로 |

## §4 거리 환산 글(`Dna.kt`)

구현 중 바뀜(approval-gate.md): 전력 줄은 "10km 이상"이 아니라 "전력 축을 판정했을 때" 100km당을 보이고, 한 가지 제안의 전력 문장도 판정했을 때만 후보다. 두 운전 비교는 환산 없이 쓴다. 아래 표는 처음 계약이다.

| 자리 | 조건 | 글 |
|---|---|---|
| 역동성 줄(`Judge.dyn`의 fact) | 판정함, 1km 이상 | 지금 그대로: "급가속 a번 · 급감속 b번 · 빠른 조향 c번 (10km당 x) · 브레이크 n번" |
| 역동성 줄 | 판정함, 1km 미만 | "<거리>km 동안 급가속 a번 · 급감속 b번 · 빠른 조향 c번 · 브레이크 n번" |
| 역동성 줄 | 판정 미룸 | 지금 그대로(환산 없음) |
| 전력 줄(`Judge.pur`의 fact) | 10km 이상 | 지금 그대로: "100km당 x kWh를 썼어요" |
| 전력 줄 | 10km 미만 | "<y>kWh를 썼어요(<거리>km)", y = kwhPer100 × km / 100(소수 한 자리). y < 0.05면 "0.1kWh보다 적게 썼어요(<거리>km)" |
| 한 가지 제안(`Coach.line`) | 10km 미만 | 전력 후보("100km당 …")를 빼고 고른다 |

거리 표기는 지금의 `km1()`(소수 한 자리 내림)이다. 축 판정 값과 보류 규칙은 그대로다.

## §5 결과 차례와 칸 이름

지금 차례: (다시 보기 칩) → 제목 줄 → 그래프 카드 → 유형 카드 → 축 카드 → 한 가지 제안 → 자막 → 차이 줄 → 각주.

바뀐 결과(`Ui.result`) 차례: (다시 보기 칩) → 제목 줄 → 그래프 카드 → 유형 카드 → **한 가지 제안 카드** → **축 카드("이번 운전 네 축" + 축 줄 넷)** → 자막 → 차이 줄 → 각주.

나의 DNA 칸 차례(가로·세로 같음, 사용자 결정): 머리 → **페이지 버튼 셋** → 유형 → 태그 줄 → 태그 근거 링크 → **"최근 운전 n번 평균"** → 막대 넷.

## §6 상태 보존(`MainActivity`)

- `onSaveInstanceState`: `page`(State 이름, 없으면 넣지 않음), `openRecord`, `comparing`, `picked`(LongArray, 고른 차례), `typesFor`, `listY`, `scrollY`(`R.id.scroll`), `seenAt`.
- `onCreate(saved)`: 되살린다. 되살린 뒤 첫 `render`가 `scrollY`로 한 번 스크롤한다.
- `onPause`: `isChangingConfigurations`가 거짓일 때만 페이지·비교를 닫는다(지금 동작).
- `render`의 "주행 중이거나 새 기록이면 닫기"는 그대로다.
